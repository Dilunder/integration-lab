# Integration Lab

Self-hosted webhook reliability testing for small development teams.

## First milestone
- Versioned event fixtures and scenarios.
- Ordered delivery, duplicates, parallel requests and delays.
- HTTP and JSON assertions, including polling a business API.
- Persistent execution history and JUnit reports for CI.
- React interface and a deliberately broken/fixed demo shop.

Stack: Java 21, Spring Boot, React (JavaScript), PostgreSQL and Docker Compose.

Implementation is in progress. This is a local development tool, not a public hosted service.
